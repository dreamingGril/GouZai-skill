## 从一个反常细节开始

一个前后矛盾的说法，一张算不过来的账单，一次身份与遭遇的错位——故事从这些地方长出来。

网络狗仔是一套基于 23 篇中文媒体样本整理的写作技能，用于标题创作、人物故事、娱乐评论、社会观察和猎奇科普。它把悬念、反差和口语锋芒放进文章，也要求每一层推进带来新的事实或解释。

> **先有冲突，再有形容词。**  
> 标题可以藏答案，决定事情性质的澄清必须留下。

## 写作能力

| 你给它什么 | 它帮你完成什么 |
| :--- | :--- |
| **一个选题** | 寻找冲突、叙述切口与需要补充的核心材料 |
| **一组事实** | 从现场开头推进到证据、解释与后果的完整文章 |
| **一份草稿** | 调整开头、节奏、段落和观点落点 |
| **一个标题** | 生成 6 个不同机制的候选，并推荐一个 |

人物故事沿时间转折展开，评论沿证据冲突展开，科普沿问题与机制展开。题材决定结构，篇幅跟随你的要求。

## 马上开写

**给一份草稿，先救开头。**

```text
使用 $network-paparazzi 改写下面的草稿。
保留事实与原意，从最有冲突的细节开头，短段落推进，
语气鲜活、有态度。推荐一个标题，再给两个不同机制的备选。
草稿：〔粘贴你的正文〕
```

**只要标题，也可以单独调用。**

```text
使用 $network-paparazzi，为下面的虚构选题起 6 个标题，
分别使用不同的悬念或反差机制，推荐一个。
选题：一个宣布戒掉手机的人，开始靠拍摄“戒手机日常”涨粉。
```

上面是调用示例；其中的选题明确为虚构，不代表已经发生的新闻。

## 一篇文章怎样推进

**事实卡 → 选冲突 → 标题机制 → 分题材写作 → 核验 → 成稿**

开头让人看见动作、原话或现场；中段用新事实继续推动；揭晓之后追问代价；结尾回扣一个具体物件或动作。

完整写作默认交付：**推荐标题 + 两个不同机制备选 + 正文 + 简短来源与待核说明**。只要标题时，交付 6 个差异化候选与推荐。

## 锋芒从哪里来

- **落在人、钱、选择与后果上。** 评论中的态度要能被具体材料支撑。
- **让证据承担力度。** 不虚构引语、目击者、金额或私人指控。
- **让读者有判断空间。** 保留关键澄清，区分已知事实与待核信息。
- **让语气随题材变化。** 不把每篇文章套进同一个三段式，不反复靠惊叹词制造刺激。

涉及实时人物状态、医学、社保、金额和引语时，需要可用的检索工具协助核验；无法核验的内容应明确标注。

## 安装

将项目中的整个 `network-paparazzi/` 文件夹复制到代理的技能目录，保留 `references/`。

```text
Codex（当前 Windows 用户）
C:\Users\12951\.codex\skills\network-paparazzi\SKILL.md

Claude Code（项目内）
.claude/skills/network-paparazzi/SKILL.md
```

下一轮对话尝试使用 `$network-paparazzi`。常规写作无需额外运行脚本；事实核验依赖所在代理的检索能力。

## 项目结构

```text
network-paparazzi/
├── SKILL.md                    风格、入口与默认交付
└── references/
    ├── workflow.md             从事实卡到成稿
    ├── title-engine.md         标题机制库
    ├── genres.md               分题材写作指南
    ├── few-shots.md            语气校准示例
    ├── corpus-analysis.md      23 篇样本拆解
    ├── fact-check.md           事实核验规则
    └── corpus-source.txt       原始语料
```

## 关于这 23 篇样本

底本为《媒体文章合集整理 (1).docx》，编号沿用原稿。样本用于分析文本结构与表达吸引力，**没有点击率、曝光量或转化数据**，不能据此声称效果已被流量实验验证。

语料里的说法需要独立核实，原题引用不构成事实背书。公开分发原始语料前，应确认相应授权。
